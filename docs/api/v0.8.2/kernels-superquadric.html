compute_superellipse_angles_kernel(const uint32_t num_quadrics, const uint32_t resolution, const float3 *scales, const float2 *exponents, SuperellipseFrame *stack_scratch, double *out_azimuths, double *out_polars) -> void

Samples the azimuthal and polar superellipses of every primitive.

One thread per curve, so two per primitive, each walking its own divide-and-conquer traversal. The parallelism is only $2K$ wide, but a parallel tree would have to re-derive the traversal order and with it the exact sample placement. The azimuth takes one extra sample across the closed period; the caller drops the last, since sampling $[-\pi, \pi]$ inclusive repeats the first column.

compute_superquadric_vertices_kernel__global__#conquer3d/csrc/primitive/superquadric.cu:248
compute_superquadric_vertices_kernel(const uint32_t num_quadrics, const uint32_t resolution, const float3 *scales, const float2 *exponents, const float *rotations, const float3 *translations, const double *azimuths, const double *polars, const bool return_labels, float3 *out_vertices, int32_t *out_labels) -> void

Places every tessellation vertex of every primitive in world space.

One thread per output vertex. The vertex layout per primitive is one south pole, then resolution - 2 interior latitude rings of resolution vertices with the azimuth varying fastest, then one north pole. The poles are placed exactly rather than evaluated: $\cos(\pm\pi/2)$ is $6\times10^{-17}$ rather than zero, and raising that to a small exponent yields a ring of finite radius instead of a point. Everything is computed in double and narrowed only on the write, because near the poles a float32 angle perturbs $\cos\eta$ by an order of magnitude and the fractional power turns that into a visible displacement, precisely on the sharp corners worth capturing.

compute_superquadric_faces_kernel__global__#conquer3d/csrc/primitive/superquadric.cu:328
compute_superquadric_faces_kernel(const uint32_t num_quadrics, const uint32_t resolution, int3 *out_triangles) -> void

Writes the triangle connectivity of every tessellated primitive.

One thread per output triangle. Connectivity depends only on resolution, so every primitive shares the same pattern shifted by its vertex offset. The triangles are emitted in four contiguous blocks: the south fan, the two halves of the interior quads, and the north fan. The azimuthal wrap is folded into the column arithmetic rather than stitched on as a separate seam, which is what leaves the surface closed with no duplicated vertices.

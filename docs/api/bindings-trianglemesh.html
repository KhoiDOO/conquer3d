conquer3d._C.TriangleMesh.build_flood_fill_band_datamethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:1750
conquer3d._C.TriangleMesh.build_flood_fill_band_data(grid_min: list[float] | None = None, grid_max: list[float] | None = None, res: list[int] | None = None, dilation_radius: int = 2, cavity_max_voxels: int = -1) -> None

Pre-computes the leak-resistant band flood fill used by sign_mode=6.

Water floods from the grid boundary and stops at the surface band dilated by dilation_radius lattice spacings, so holes up to about 2 * dilation_radius + 3 spacings across are sealed; small cavities the dilation encloses are released and the band is resolved by neighbour agreement. Memory scales with surface area, like sign_mode=5.

The wall trades thin detail for leak resistance: solid parts thinner than about 2 * dilation_radius + 3 spacings vanish, slots narrower than 3 spacings fill in, and a sealed-off pocket holding more than cavity_max_voxels free vertices stays interior.

Parameters
NameTypeDefaultDescription
grid_minList[float]the mesh bounds padded by (r + 3) * E / (res - 1 - 2 * (r + 3)), with E the largest extentLower grid corner [x, y, z]. When either bound is omitted, both default to the mesh bounds padded by (r + 3) E / (res - 1 - 2 (r + 3)), with E the largest extent.
grid_maxList[float]optionalUpper grid corner [x, y, z].
resList[int][128, 128, 128]Vertices per axis [rx, ry, rz]. Defaults to [128, 128, 128].
dilation_radiusint2Chebyshev dilation radius in spacings. Defaults to 2.
cavity_max_voxelsint-1Largest interior component, in vertices, released for resolution; -1 selects (2 * dilation_radius + 1)^3 and 0 disables the release. Defaults to -1.
Raises
NameDescription
RuntimeErrorIf explicit bounds leave less than dilation_radius + 2 spacings between the mesh and the grid boundary; the message names the padding required.
Example

conquer3d._C.TriangleMesh.compute_laplacianmethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:2085
conquer3d._C.TriangleMesh.compute_laplacian(mode: int = 0) -> torch.Tensor

Computes a Laplace-Beltrami vector field on the mesh vertices.

The mode picks two independent choices at once, the edge weights and the normalisation:

===== ========== ================= ================================================== mode weights normalisation result ===== ========== ================= ================================================== 0 uniform sum of weights umbrella average, units of length 1 cotangent twice the area mean curvature normal $-2H\hat{n}$, units of 1/length 2 cotangent sum of weights weighted neighbour average, units of length ===== ========== ================= ==================================================

Mode 1 is the operator curvature is built on. Modes 0 and 2 are convex combinations of the neighbour offsets, so adding a fraction of them to a position is a stable smoothing step at any mesh scale; mode 2 follows the surface geometry where mode 0 also relaxes the triangulation.

Parameters
NameTypeDefaultDescription
modeint0Weighting and normalisation, per the table. Defaults to 0.
Returns
torch.Tensor

(N, 3) float32 Laplacian vectors.

Raises
NameDescription
RuntimeErrorIf mode is not 0, 1 or 2.
Note

Modes 0 and 1 are cached on the mesh; mode 2 is recomputed on each call, since its weights depend on vertex positions that a caller may be moving between calls. Mode 2 and smooth() share one per-edge weight definition and differ only in clamping: mode 2 reads the weights raw, while smooth() bounds and clips them as the reference implementation does, so the two diverge on meshes with obtuse angles.

Example
>>> curvature_normal = mesh.compute_laplacian(mode=1)
>>> smoothing_step = mesh.compute_laplacian(mode=2)

conquer3d._C.TriangleMesh.fairmethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:2185
conquer3d._C.TriangleMesh.fair(k: int = 2, iterations: int = 500, damping: float = 0.10000000149011612, mode: int = 1, locked: torch.Tensor | None = None, normal_only: bool = False) -> None

Higher-order Laplacian fairing of the vertex positions, in place (Botsch et al., Polygon Mesh Processing, Section 4.3).

Replaces the free region with the surface satisfying $\Delta^k x = 0$, reached by explicit Euler steps of $\partial x/\partial t = (-1)^{k+1} \lambda \Delta^k x$:

===== ==================== ============== =========================================== k Euler-Lagrange PDE rim continuity surface ===== ==================== ============== =========================================== 1 $\Delta x = 0$ $C^0$ membrane, minimising area 2 $\Delta^2 x = 0$ $C^1$ thin plate, minimising curvature 3 $\Delta^3 x = 0$ $C^2$ minimum variation, minimising its change ===== ==================== ============== ===========================================

Order k holds k rings of boundary vertices fixed, which is what gives the $C^{k-1}$ continuity at the border. fair(k=1, ...) is smooth(...).

Parameters
NameTypeDefaultDescription
kint2Order of the flow, at least 1. Defaults to 2.
iterationsint500Number of explicit steps. Defaults to 500.
dampingfloatoptionalStep factor, stable up to $2^{1-k}$. Defaults to 0.1.
modeint1Weighting. 0 uses uniform weights, 1 cotangent weights. Defaults to 1.
lockedtorch.TensorNone(N,) bool mask, True where a vertex is held fixed. Unioned with the boundary rim and grown with it, so the set actually pinned is wider than the mask given by k - 1 rings. Defaults to None.
normal_onlyboolFalseIf True, move each vertex only along its normal, so the shape changes while the triangulation stays put. Defaults to False.
Raises
NameDescription
RuntimeErrorIf k is below 1, or mode is not 0 or 1.
RuntimeErrorIf locked is not a contiguous CUDA bool tensor of shape (N,) on the same device as the mesh.
Note

Moving the vertices invalidates the geometric caches (normals, areas, curvature, BVH, flood fills); they are rebuilt on next use. Topology is untouched.

Example
>>> mesh.fair(k=2, iterations=500, damping=0.1)
>>> mesh.fair(k=3, damping=0.05)      # minimum variation, C2 at the rim

conquer3d._C.TriangleMesh.get_mean_curvaturemethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:2038
conquer3d._C.TriangleMesh.get_mean_curvature(mode: int = 0) -> torch.Tensor

Computes discrete Mean curvature from the cotangent Laplace-Beltrami operator.

The operator evaluates the mean curvature normal $\Delta_{LB} v = -2 H \hat{n}$, which points opposite the vertex normal on a convex surface, so a sphere of radius $R$ with outward normals reports $H = +1/R$ in mode 0.

Parameters
NameTypeDefaultDescription
modeintoptionalQuantity to return. Defaults to 0. - 0: signed mean curvature $H_i = -\frac{1}{2} \Delta_{LB} v_i \cdot \hat{n}_i$, shape (N,). - 1: mean curvature normal $\Delta_{LB} v = -2 H \hat{n}$, shape (N, 3). - 2: absolute mean curvature $\frac{1}{2} \|\Delta_{LB} v\|$, shape (N,), Equation (3.13) of Botsch et al., Polygon Mesh Processing. It drops the sign and keeps the tangential part of the discrete operator, so it sits slightly above |H| from mode 0.
Returns
torch.Tensor

(N,) float32 curvature for modes 0 and 2, or (N, 3) float32 curvature normal for mode 1.

Raises
NameDescription
RuntimeErrorIf mode is not 0, 1 or 2.
Example
>>> mean_curv = mesh.get_mean_curvature()
>>> curv_normal = mesh.get_mean_curvature(mode=1)
>>> abs_curv = mesh.get_mean_curvature(mode=2)

conquer3d._C.TriangleMesh.get_principal_curvaturesmethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:2067
conquer3d._C.TriangleMesh.get_principal_curvatures() -> torch.Tensor

Computes principal curvatures $k_1 = H + \sqrt{\max(0, H^2 - K)}$ and $k_2 = H - \sqrt{\max(0, H^2 - K)}$, following Botsch et al., Polygon Mesh Processing: $H$ is the absolute mean curvature of Equation (3.13) (get_mean_curvature(mode=2)) and $K$ the Gaussian curvature of Equation (3.14).

Because that $H$ carries no sign, an elliptic region curving away from the normals reports positive $k_1$ and $k_2$ where the true pair is negative; magnitudes are unaffected, and hyperbolic points still come out with opposite signs. Use get_mean_curvature(mode=0) when the sign matters.

Returns
torch.Tensor

(N, 2) float32 tensor whose columns hold $k_1 \ge k_2$.

Example
>>> k1, k2 = mesh.get_principal_curvatures().unbind(1)

conquer3d._C.TriangleMesh.smoothmethod#conquer3d/csrc/binds/data_structure/triangle_mesh.cpp:2147
conquer3d._C.TriangleMesh.smooth(iterations: int = 10, damping: float = 0.5, mode: int = 1, locked: torch.Tensor | None = None, normal_only: bool = False) -> None

Laplacian smoothing of the vertex positions, in place (Botsch et al., Polygon Mesh Processing, Chapter 4).

Each iteration is one explicit Euler step of the diffusion equation, moving every free vertex a fraction of the way to the weighted average of its neighbours: $x_i \leftarrow x_i + \texttt{damping} \cdot \frac{\sum_j w_{ij}(x_j - x_i)}{\sum_j w_{ij}}$. Normalising by the weight sum, rather than by vertex area, keeps a fixed damping stable at any mesh scale. Boundary vertices are pinned.

Parameters
NameTypeDefaultDescription
iterationsint10Number of explicit steps. Defaults to 10.
dampingfloatoptionalStep factor, typically in [0, 1]. Defaults to 0.5.
modeint1Weighting. 0 uses uniform weights, which smooth the geometry and also relax the triangulation tangentially; 1 uses cotangent weights, which follow the surface geometry and preserve triangle shapes. Defaults to 1.
lockedtorch.TensorNone, which pins the rim alone(N,) bool mask, True where a vertex is held fixed. Unioned with the boundary pin rather than replacing it, so an open mesh keeps its rim whether or not a mask is given. Defaults to None, which pins the rim alone.
normal_onlyboolFalseIf True, move each vertex only along its normal, so the shape changes while the triangulation stays put. Defaults to False.
Raises
NameDescription
RuntimeErrorIf mode is not 0 or 1.
RuntimeErrorIf locked is not a contiguous CUDA bool tensor of shape (N,) on the same device as the mesh.
Note

Moving the vertices invalidates the geometric caches (normals, areas, curvature, BVH, flood fills); they are rebuilt on next use. Topology is untouched. Cotangent weights are rebuilt every iteration, since they depend on the positions being moved.

Example
>>> mesh.smooth(iterations=10, damping=0.5, mode=1)
>>> mesh.smooth(locked=keep_these)    # smooth everything except a pinned region
